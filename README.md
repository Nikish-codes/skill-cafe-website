# Skill Café 3.0

The official website for **Skill Café 3.0** — an interdisciplinary challenge presented by the Centre of Talent Development (COTD) at Woxsen University, in collaboration with Google and the Ideate Club.

## Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + custom design tokens
- **Motion:** Framer Motion (velocity-linked gesture & marquee animation)
- **Icons:** Material Symbols Rounded & Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Nikish-codes/skill-cafe.git

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
